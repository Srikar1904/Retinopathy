RetinaCare AI Capabilities

More than a prediction.

RetinaCare AI combines deep-learning classification, explainable AI, screening results and patient-facing tools into one integrated diabetic retinopathy screening prototype.

Core capabilities

Built around the complete screening experience.

From uploading a retinal image to reviewing the prediction, RetinaCare AI connects the machine-learning model with practical web application features.

Patient tools

Results that remain accessible.

RetinaCare AI doesn't stop after the prediction. The application also provides account-based history and report functionality.

🗂️

Patient History

Completed scans can be saved against the logged-in user's account and displayed through the Patient History page with stage, confidence and scan date.

📥

Screening Report

Users can download a generated report containing the screening result, model confidence, risk level, inference information and project model details.

🔐

User Authentication

The application includes registration, login and password-update functionality connected to the backend database.

⚡

Full-Stack Integration

The frontend, Node.js application backend, Python ML service and MySQL database work together as one connected application.

Important: RetinaCare AI is an AI-assisted screening and research prototype. Model confidence is not a calibrated medical probability, and Grad-CAM is an explanatory visualization, not definitive lesion detection. The system should not be used as a substitute for evaluation by a qualified healthcare professional.
