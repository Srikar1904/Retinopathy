End-to-end workflow

Six steps from image to explanation.

Each stage has a specific role in the RetinaCare AI screening workflow, keeping the system modular, traceable and explainable.

01
📷

Image Acquisition

A retinal fundus image is uploaded through the Live Demo interface. The system accepts common image formats such as JPEG and PNG.

IMAGE INPUT
02
⚙

Image Preparation

The uploaded image is converted into the format required by the model and resized to 224 × 224 pixels before ResNet-50 preprocessing.

224 × 224
03
🧠

ResNet-50 Inference

The processed retinal image is passed through the trained ResNet-50 architecture to extract deep visual features and generate class scores.

TENSORFLOW
04
◉

Five-Stage Classification

The model selects the highest-scoring class from five categories: No DR, Mild, Moderate, Severe and Proliferative.

5 CLASSES
05
🔥

Grad-CAM Explanation

Grad-CAM generates a visual heatmap showing image regions that contributed to the model's selected prediction.

XAI
06
📄

Screening Report

The interface presents the predicted stage, model confidence, risk-level indicator, recommendations and downloadable report.

OUTPUT

Explainable AI

Don't just show the answer. Show the reasoning.

RetinaCare AI uses Grad-CAM to generate a visual explanation of the model prediction. The heatmap highlights image regions that contributed to the selected class.

This makes the screening prototype easier to inspect and provides an additional visual layer alongside the model's classification result.

GRAD-CAM · MODEL ATTENTION VISUALIZATION
System output

What the user receives.

The final interface combines the model result with supporting information so that the prediction can be reviewed within the screening workflow.

◉

Predicted Stage

One of five diabetic retinopathy severity classes selected by the trained model.

%

Model Confidence

The softmax score associated with the selected prediction, presented as model confidence.

🔥

Grad-CAM

A heatmap visualization showing regions contributing to the selected prediction.

Important: RetinaCare AI is an AI-assisted screening and research prototype. Model confidence is not a calibrated medical probability, and Grad-CAM is an explanatory visualization, not definitive lesion detection. Results should not replace evaluation by a qualified healthcare professional.
